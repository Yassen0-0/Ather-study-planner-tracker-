## Prioritized Needs (top 10)

1. **P0 — Guard Firebase absence off Android:** make `authRepositoryProvider` tolerate a failed `initializeApp` (lazy/handle-less `AuthRepository` returning signed-out), so Windows boots and a broken boot doesn't also mean zero telemetry (lib/presentation/providers/auth_providers.dart:13, lib/app/app.dart:26).
2. **P1 — Stop empty uploads erasing the cloud copy after a failed restore:** gate `flush()` on "a restore attempt has succeeded or genuinely never needed" (e.g., persist last-successful-download marker; refuse upload while local is empty and a cloud doc newer than it existed), lib/presentation/providers/backup_providers.dart:124.
3. **P1 — Fix ReviewScheduler's first-pass empty read:** await `snapshotProvider.future` in `_sync` instead of reading `snapshotValueProvider` (notification_providers.dart:133), eliminating the per-launch cancel-all window.
4. **P1/P2 — Log in `ReviewScheduler`'s catch** (notification_providers.dart:164): one debugPrint/Crashlytics line converts "reminders quietly dead" back into a diagnosable event; pair with a Settings surface if the pass keeps failing.
5. **P2 — Surface auto-restore failure** in `backup_gate.dart:220` (at minimum debugPrint + SyncStatus.failed so the Settings card says the pull didn't happen).
6. **P2 — Reject invisible-only names:** extend the prompt validation past `trim().isNotEmpty` to strip Cf/ZWSP/tatweel before judging emptiness (prompts.dart:61), keeping storage as-typed otherwise.
7. **P2 — Handle decimal separators consciously in NumberField:** either reject paste containing separators with the existing error banner, or translate `.`/`٫` explicitly rather than concatenating digits (ather_controls.dart:398).
8. **P2 — Deep-link landing for missing lesson:** toast + pop (or dashboard redirect) when `lessonSummaryProvider(id)` is null from a notification tap (notification_providers.dart:183, lesson_screen.dart:95).
9. **P2 — Resolve timezone properly:** use `flutter_timezone`/platform channel for the IANA id (fallback Cairo), and re-run `setLocalLocation` on resume so travel/DST don't strand the session's zone (review_notification_service.dart:88, 450).
10. **P2 — Small correctness sweeps:** clear `exam_draft_*` keys in the account-switch wipe (backup_gate.dart:91); add `permanentlyLockedOut` to the lockout-message branch (lock_screen.dart:137); add a widget test for the B-03 window and the B-02 offline-restore→flush sequence; verify `zonedSchedule` on the Windows plugin before advertising the desktop build.
